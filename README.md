# States of Matter Simulation

## Overview
States of Matter is an interactive educational simulation developed in Unity 3D that demonstrates the behavior of particles in the three primary states of matter: Solid, Liquid, and Gas. The simulation helps users visualize how particles move, interact, and arrange themselves in each state, making it easier to understand fundamental scientific concepts through real-time observation.

## Features
- Interactive particle-based simulation
- Visualization of Solid, Liquid, and Gas states
- Real-time particle movement and behavior
- Educational and easy-to-understand interface
- Physics-driven particle interactions
- Suitable for students and science enthusiasts

## Learning Outcomes
Through this simulation, users can:
- Understand particle arrangement in different states of matter
- Observe how particle movement changes between solids, liquids, and gases
- Learn about intermolecular spacing and particle interactions
- Visualize scientific concepts that are difficult to observe in real life

## Technology Stack
- Unity 3D
- C#
- Unity Physics System
- Unity UI

## About the Project
This project was created to provide an engaging and interactive way to learn the fundamentals of matter. Instead of relying solely on textbook diagrams, users can directly observe particle behavior and compare the characteristics of each state of matter in a dynamic environment.
